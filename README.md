# anomaly-mvtec
Contexte métier/scientifique. Le coût d’un défaut non détecté (rappels, sécurité, image de marque) est élevé, tout comme celui des fausses alarmes (rebuts inutiles, arrêts de ligne). Scientifiquement, on s’appuie sur les modèles génératifs (VAE), l’apprentissage de représentations (contrastif, ViT) et la fiabilité des scores d’anomalie.
